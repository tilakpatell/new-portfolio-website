# Phase 1 evidence: the 2017 heroes, their hilts, the duel

- `heroes-1.jpg`, `heroes-2.jpg`: each of the thirteen heroes as imported (`public/models/galaxy/bf2017/crew/<kind>.glb`: the game's LOD0 mesh, every map at the game's 2048, WebP 90), front, three-quarter and face, beside the Meshy or Sketchfab figure the galaxy walked before (Anakin and Bossk had none on the crew; Luke's, Han's, Leia's, Vader's and Palpatine's stay for the worlds and tools outside the galaxy that load them, the other five went). The sheets show the full-map files, now each hero's `.ultra.glb`; the plain cut is that mesh at 1024 colour and 512 maps. Shot with `scripts/glb-shot.mjs … front,three,face`.
- `hilts-blasters.jpg`: the ten hilts and three hero blasters (`public/models/galaxy/surface/`), side on, in the frame the game modelled them in: the grip at the origin, a hilt's emitter up +y, a barrel along +z.
- `duel-*.png`: the duel in the browser (dev server, `QUALITY=high`, software GL), through the dev hook `__surfaceDo('duel', kind)`: Luke against Maul on Hoth, Luke against Vader on Endor; at guard, mid-strike and clashing. (In `duel-endor-strike.png` Vader is still arriving: his full file is 7.7 MB, and in software GL he is whole four seconds later, `duel-endor-clash.png`.)
