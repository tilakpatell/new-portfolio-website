# Kamino Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kamino's surface with every person, droid and creature a real model (never primitives, even on failure), a rigged named cast, three interiors, four things to do, its own look, zero console errors.

**Architecture:** A site flag `figures: 'models'` swaps the three figure resolvers (life, quest spawns, ground war) for one that walks a chain of real models (`figurePolicy.js`) and hides what has none. New models come from the existing Meshy pipeline (`scripts/meshy-galaxy.mjs`) onto the shared Meshy skeleton. Interiors use the zone engine; quests use `quests.js` steps; the battle uses the assault engine or quest waves.

**Tech Stack:** React 18, three.js, Vite, Vitest, Playwright (QA scripts only), Meshy (offline, scripts only).

**Spec:** `docs/superpowers/specs/2026-10-09-kamino-design.md`

## Review Focus

1. A model file 404s or fails to parse mid-session: the actor is hidden, `missing()` lists it, no blob appears. Pinned in Task 2.1's `modelOnly` tests (all resolvers throw / return null).
2. The ground war's side flips to the Hutts while you're on Kamino: mercenaries arrive as cartel crew models, never built. Pinned in Task 2.3 and 2.6.
3. A crew model whose rig is a statue (Meshy refused): `crewFigure` returns a still figure, not null; the chain still yields a model. Pinned in Task 3.2's rows test.
4. A spawn, giver or door placed off a deck: the person falls to the sea or the quest can't start. Pinned in Task 2.5's floor tests and re-run every PR.
5. A material whose vertex program lost `mvPosition` gets the sky-fog line: a shader error, the material drawn as nothing. Pinned in Task 2.4.

- [ ] **Step 3: Implement**

```js
// Who may be drawn as what on a world that takes models only
// (site.figures === 'models': Kamino first). A kind is tried as a walker
// machine, its crew figure, then its catalogue model, and then each of its
// STANDINS the same way: another real model of the same role. Never a
// figure built from primitives (figures.js) or a prop: what has no model
// comes back null, the actor stays hidden, and missing() says so, for the
// QA run (scripts/kamino-check.mjs). The design:
// docs/superpowers/specs/2026-10-09-kamino-design.md §1.
import { CREW } from './crewList';
import { SURFACE_MODELS } from './catalog';
import { WALKERS } from './walkers';

// kind → other kinds whose models play the same part when its own won't load
export const STANDINS = {
  // (the Phase I armour's statue first, then the rigged Phase II trooper)
  clonephase1: ['clone'],
  // (the other Fett in Mandalorian armour, his son grown)
  jango: ['bobafett'],
  // (hidden rather than wrong: nobody stands in for a child or a sea beast)
  youngboba: [],
  aiwha: [],
};

const tablesOf = ({ crew = CREW, models = SURFACE_MODELS, walkers = WALKERS } = {}) => ({ crew, models, walkers });

export const hasModel = (kind, tables) => {
  const t = tablesOf(tables);
  return Boolean(t.walkers[kind] || t.crew[kind] || t.models[kind]);
};

export const modelChain = (kind, tables) => [kind, ...(STANDINS[kind] ?? [])].filter((k, i, all) => all.indexOf(k) === i && hasModel(k, tables));

const gone = new Map(); // kind → why
export const missing = () => [...gone].map(([kind, why]) => ({ kind, why }));
export const forgetMissing = () => gone.clear();

export async function modelOnly(kind, spec = {}, i = 0, resolvers, tables) {
  const chain = modelChain(kind, tables);
  for (const k of chain) {
    for (const make of [resolvers.walker, resolvers.crew, resolvers.model]) {
      const fig = await Promise.resolve()
        .then(() => make(k, spec, i))
        .catch(() => null);
      if (fig) return fig;
    }
  }
  if (!gone.has(kind)) {
    const why = chain.length ? 'its models failed to load' : 'no model';
    gone.set(kind, why);
    console.warn(`[surface] ${kind}: ${why}; hidden, not built`);
  }
  return null;
}
```
