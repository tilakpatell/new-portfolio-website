# Kamino Implementation Plan (Phases 1 and 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every figure on Kamino drawn from a GLB and walking on clips, held there by the runtime and by a test; then Kamino moved into its own site file and Slave I and the pads made the film's.

**Architecture:** Six Meshy figures land as crew rows (`crewList.js`), which `anyFigure` already tries before the catalogue's statues. A site flag `figures: 'models'` takes `buildFigure` out of every resolver (actors, quest spawns, the ground war, the assault). The figures audit learns every source of a figure and a `MODELS_ONLY` list; a vitest runs it over the real tables.

**Tech Stack:** three.js, Vite, Vitest, gltf-transform, Meshy's API (`scripts/meshy-galaxy.mjs`), Playwright-core on the cached Chromium (Metal).

**Spec:** `docs/superpowers/specs/2026-10-09-kamino-design.md`. Phases 3–7 get their own plan, appended here, when Phase 2 has landed.

## Global Constraints

- Files under 800 lines; logic that can be tested without a canvas is pure and tested beside its file (`x.js` → `x.test.js`, under a second, no network).
- One art a world: Kamino is `scanned`. No new dependency.
- British spelling, curly quotes in prose and in-game text; the films' and shows' own short lines at most.
- Meshy: the third account only (`node --env-file=$HOME/.tilakverse-meshy3.env …`); say the batch total before spending; never print the key; prompts describe looks, never names.
- New site-made GLBs under `public/models/galaxy/crew/` go into `scripts/ai-e2e/assets/allow-uncredited.json` (the credits audit).
- Before each PR: `npm run lint`, `npm test`, `npm run build`, `node scripts/health.mjs --check --skip build`, all green; then merge `origin/main` in, trial-merge against open branches (`git merge-tree --write-tree --name-only HEAD <branch>`), `gh pr create`, `gh pr merge --merge`.
- A move changes no pixel (the rules' recipe): shots before and after are byte-equal but for what moves on the clock.

```js
// Which book of figures scripts/meshy-galaxy.mjs works from: its own, or
// its own with a lane's (MESHY_LANE=kamino: scripts/meshy-kamino.mjs), whose
// tasks are kept in a file of the lane's so its task ids stay together on
// the account that made them, and whose names are the ones run by default.
import { join } from 'node:path';

export function laneOf(env, base, lanes, dir = 'scripts') {
  const id = env.MESHY_LANE;
  if (!id) return { assets: base, tasks: join(dir, 'meshy-galaxy-tasks.json'), names: Object.keys(base) };
  const lane = lanes[id];
  if (!lane) throw new Error(`no lane ${id}`);
  return { assets: { ...base, ...lane }, tasks: join(dir, `meshy-${id}-tasks.json`), names: Object.keys(lane) };
}
```

```js
const later = (ms) => new Promise((r) => setTimeout(r, ms));
// … `built: false` (a world drawn in models only, its site's `figures:
// 'models'`): never a built figure; a kind whose models all fail is tried
// once more after `retry` ms, then a humanoid prop, then nothing
export async function anyFigure(kind, spec = {}, kit = null, i = 0, models = SURFACE_MODELS, { built = true, retry = 2000 } = {}) {
  if (spec.model === false && built) return buildFigure(kind) ?? propFigure(kind, spec, kit, i);
  const modelled = async () => {
    // (a machine on legs its model came without: cut at its joints and walked, its rider up top; walkers.js)
    const walker = WALKERS[kind] ? await walkerFigure(kind, i, models).catch(() => null) : null;
    return walker ?? (await crewFigure(kind, i)) ?? (await modelFigure(kind, models));
  };
  const fig = await modelled();
  if (fig) return fig;
  if (built) return buildFigure(kind) ?? propFigure(kind, spec, kit, i);
  if (retry > 0 && (CREW[kind] || models[kind] || WALKERS[kind])) {
    await later(retry);
    const again = await modelled();
    if (again) return again;
  }
  return propFigure(kind, spec, kit, i);
}
```

- [ ] **Step 3: Implement**:

```js
// every figure a world can have, and where it comes from: its people and
// its zones' (siteOf has merged the quests' people into its life), its
// quests' spawns, the soldiers of any side that could hold it in the war
// (ground/troops.js's FAMILIES: who holds a world changes), and its
// assault's sides
export function sources(id, site, { FAMILIES = {}, ASSAULTS = {} } = {}) {
  const out = [];
  const add = (kind, from) => kind && out.push({ kind, from });
  for (const a of site.life ?? []) add(a.kind, a.zone ? 'zone' : 'life');
  for (const z of site.zones ?? []) for (const a of z.life ?? []) add(a.kind, 'zone');
  for (const q of site.quests ?? []) for (const st of q.steps ?? []) for (const s of [].concat(st.spawn ?? [])) add(s.kind, 'spawn');
  for (const kinds of Object.values(FAMILIES)) for (const k of kinds) add(k, 'war');
  const as = ASSAULTS[id];
  if (as) for (const side of [as.sides?.attack, as.sides?.defend]) for (const [k] of side?.kinds ?? []) add(k, 'assault');
  return out;
}

// the worlds drawn in models only (their site's `figures: 'models'`), and
// the machines and creatures that may stand still on one
export const MODELS_ONLY = ['kamino'];
export const STILL_OK = new Set(['r5', 'aiwha', 'probe', 'astromech', 'mousedroid']);
export function strays(rows, only = MODELS_ONLY) {
  const out = [];
  for (const r of rows)
    for (const world of r.worlds)
      if (only.includes(world) && (r.how === 'built' || r.how === 'none' || (r.how === 'still' && !STILL_OK.has(r.kind)))) out.push({ kind: r.kind, how: r.how, world });
  return out;
}
```
