# Bree Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bree as a second walkable town, a chapter of the Middle-earth page between the Shire and Rivendell, with five scenes from the films.

**Architecture:** Generic, pure parts under `src/components/middleearth/towns/` (walker, watchers, talk, story) with tests, generic drawing parts (rain, ground, bake) and HUD parts (`TownHud.jsx`); Bree's data, rules, builders, inside scene, 3D scene and component under `towns/bree/`, following the Shire's split (rules / scene / component).

**Tech Stack:** React 18, three.js (the repo's version), Vitest, ESLint; headless Chromium (playwright-core) for checks.

**Spec:** `docs/superpowers/specs/2026-10-04-bree-town-design.md`

## Global Constraints

- Metres; +x east, +z south; `face` turns +x to (cos face, −sin face); a box collider's `turn` equals the builder's `rotation.y`.
- Hobbit 1.55 tall; Big Folk about 2.3; walk 3.4 m/s, run 6.2 m/s, radius 0.4 (the Shire's `HOBBIT`).
- Walkable disc radius 46; stockade radius 34; Bree chapter `at: [262, 200]`, `stop: 'bree'`.
- Seals: `breegate`, `underhill`, `pints`, `strider`, `slipaway`.
- localStorage `tp-bree-done` (array of quest ids) and `tp-bree-at` ({ x, z, face }), JSON through `lib/hooks`' `local`.
- Dev hook `window.__BREE__ = { api, sim, complete }`, only in `import.meta.env.DEV`.
- No downloads: `WORLD_MB['/middle-earth']` stays 1.
- Code style as the Shire's files: plain-English comments, no TypeScript, named exports.

## Review Focus

- A saved position from an older layout lands inside a house or outside the disc → `validAt` puts it back at the start (test in Task 6).
- Saved progress holds unknown ids or skips a step → `progress` ignores unknown ids and treats a quest as open only when what it needs is done (test in Task 4).
- Leaving the page mid-scene (inside the inn, mid-pour, mid-sneak) → coming back puts you outdoors at the inn door with the scene not done (Task 11, checked in the browser in Task 13).
- Pouring on a touch screen → press-and-hold on the tap button pours, and lifting the finger stops it, with no page scroll (Task 11, browser check in Task 13).
- A key press while a HUD button has focus → acts once, not twice (Task 11 copies the Shire's `HTMLButtonElement` guard).
