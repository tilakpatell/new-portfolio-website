# Battlefront 2017 pipeline, phase 0: the tools. Implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A session can take any model named in the Supabase drop's manifest, fetch it with its textures, and turn it into the site's cuts, catalogue row and credit with one command each, proven on one committed fixture, without any 2017 model yet shipping.

**Architecture:** Two CLIs under `scripts/` (`bf2017-fetch.mjs`, `bf2017-import.mjs`) over three pure, tested modules under `scripts/lib/` (manifest reading and cut picking; the glTF image-URI parse and texture-source choice; KTX2 unpack and the ORM recipe). A rig is kept whole: every joint as it comes, no pruning, no renaming (the owner's ruling of 2026-10-10: the game's skeleton is the contract). The import reuses `scripts/lib/surface-model.mjs` for grounding and the gltf-transform pipeline `battlefront-import.mjs` already runs, and the catalogue and credit writers move out of `battlefront-import.mjs` into a shared `scripts/lib/catalog-write.mjs` so both importers share one. A new, empty catalogue group `catalog/bf2017.js` joins `GROUPS` last.

**Tech Stack:** Node 22 (`fetch`, `--env-file`), `@gltf-transform/{core,extensions,functions}`, `meshoptimizer`, `sharp` (through ndarray-pixels' require, as `battlefront-import.mjs` does), `basisu` (the binary `scripts/ktx2.mjs` finds), Vitest. No new dependency, so no stack page.

**Spec:** `docs/superpowers/specs/2026-10-10-battlefront-2017-asset-pipeline-design.md` (sections 1 to 3, 8). The numbers: `docs/superpowers/evidence/bf2017-assets/inventory.md`.

## Global Constraints

- Output paths: `public/models/galaxy/surface/<kind>.glb`, `<kind>.lod1.glb`, `<kind>.ultra.glb`; crew to `public/models/galaxy/crew/<kind>.glb`. Caps from `catalog.test.js`: plain under 2.5 MB (4 MB with `hero: true`), `.lod1` under 0.7× the plain, `.ultra` under 24 MiB with `ultra.tris ≤ 4 × tris` and `ultra.tex ≤ 8192`.
- A kind is `/^[a-z0-9]+$/`. The credit key is `surface-<kind>`; `license: 'permission'`; the permission text is exactly: `From EA DICE’s Star Wars Battlefront II (2017), used with permission on this non-commercial fan project; Star Wars and everything in it belong to Lucasfilm.`

- Files under 800 lines; pure logic in tested modules beside the script; tests under a second, no network. British spelling, curly quotes in prose, comments say why.
- Before the PR: `npm run lint`, `npm test`, `npm run build`, `node scripts/health.mjs --check --skip build`.

## Review Focus

1. A manifest entry whose LOD chain has no cut small enough for `.lod1` (a 288-triangle cable hanger, or a one-LOD model): the picker returns the smallest LOD, never throws, and the import does not write a `.lod1` that is not under 0.7× the plain (task 2's `cutsFor` tests the one-LOD case; task 6's import test asserts no `.lod1` is written when the pick equals the plain).
2. A GLB whose image URIs are already absolute or lack the `../` prefix: `imageUris` returns them normalised to a bucket path under `web/`, so the fetch asks for the right object (task 3 tests both shapes).
3. A texture present as KTX2 but not PNG, and the reverse: `textureSources` lists PNG first and the fetch takes the first that exists; the import's `unpackKtx2` is used only when the PNG is absent (task 3 and task 5 tests).
4. A rigged model whose parts (task 6's `--parts`) each carry their own copy of the skeleton: the merge must bind every part to one skin and one set of joints, or the figure doubles its bones (task 6's import test runs the hilt only; the first rigged import in phase 1 checks `skins.length === 1` and the joint count equal to the body's, and phase 1's plan says so).
5. A sequel-era name passed to the import: refused with one line and exit 2, nothing written (task 6).

### Task 3: The fetch

**Files:**
- Create: `scripts/lib/bf2017-paths.mjs`, `scripts/lib/bf2017-paths.test.mjs`, `scripts/bf2017-fetch.mjs`

**Interfaces:**
- Consumes: task 2's `readManifest`, `partsOf`.
- Produces:
  - `imageUris(glb: Uint8Array | Buffer) → string[]`: parses the GLB's JSON chunk (magic `glTF`, chunk 0 at byte 20, length at byte 12) and returns each `images[i].uri` resolved against the GLB's own bucket path's folder into a bucket path (`web/textures/...`), with `../` segments collapsed; a URI already starting `web/` or `textures/` is returned as `web/<rest>`; data URIs are skipped.
  - `textureSources(bucketPath: string) → string[]`: for `web/textures/a/b_cs.ktx2` returns `['web/textures/a/b_cs.png', 'web/textures/a/b_cs.ktx2']` (PNG first; for a derived name such as `b_nm__normal.ktx2` or `b_nm__orm_<hex>.ktx2`, the PNG candidate is the source map's, `b_nm.png`, then the KTX2 itself).
  - `localPath(root, bucketPath) → string`: `join(root, bucketPath)` (the bucket's layout kept, so a GLB's relative URIs resolve on disk).
  - `objectUrl(base, bucket, path) → string`: `${base}/storage/v1/object/${bucket}/${path}` with each path segment URI-encoded.
  - CLI `scripts/bf2017-fetch.mjs`:
    ```
    node --env-file=.env.local scripts/bf2017-fetch.mjs manifest
    node --env-file=.env.local scripts/bf2017-fetch.mjs <name> [--lod all|<n>[,<n>…]] [--parts '<glob>,…'] [--no-textures] [--collision]
    node --env-file=.env.local scripts/bf2017-fetch.mjs --list '<glob over name>'
    ```
    `manifest` writes `lab/assets/bf2017/web/models.jsonl`. `<name>` fetches the entry's LODs (`--lod all` default), each GLB's textures by `imageUris` then `textureSources` (first that answers 200), the parts named by `--parts`, and with `--collision` the manifest's `collision.file`. Skips a file already on disk with the same byte size. Prints one line per file: path, bytes, `fetched` or `kept` or `missing` (a texture none of whose sources exist: not an error, the import will say what is missing). Exits 2 with `Set SUPABASE_URL and BF2017_KEY in .env.local and run with node --env-file=.env.local.` when either is empty. Headers: `apikey: <key>`, `Authorization: Bearer <key>`. Retries a failed GET three times with 1 s, 2 s, 4 s waits.

### Task 5: Textures from the drop

**Files:**
- Create: `scripts/lib/bf2017-textures.mjs`, `scripts/lib/bf2017-textures.test.mjs`

**Interfaces:**
- Consumes: `encodeImage` from `scripts/ktx2.mjs` (to make a tiny KTX2 in the test), `basisuPath` (not exported today: export it from `scripts/ktx2.mjs`, one-line change, and its header line).
- Produces:
  - `unpackKtx2(file, outDir, { basisu = basisuPath() } = {}) → Promise<string>`: runs `basisu -unpack -no_ktx <file>` with `cwd: outDir`, returns the path of the level-0 RGBA PNG (`<stem>_unpacked_rgba_<FORMAT>_0_0000.png`, preferring a FORMAT of `RGBA32` then `ASTC_RGBA`), and deletes every other file basisu wrote. Throws with basisu's last line when it fails.
  - `parseDerived(derived: string[]) → { normal: string[], orm: { from: string, ao: Channel | null, rough: Channel | null, metal: Channel | null }[] }` where `Channel = { map: string, ch: 'r'|'g'|'b'|'a' }`, from strings shaped `normal:<map>` and `orm:<map>:ao=<map>|<ch>;rough=<map>|<ch>;metal=<map>|<ch>` (an empty `<map>` means `null`).

  - `normalPng(buffer) → Promise<Buffer>`: keeps R and G, sets B to 255 and A to 255 (the drop's normals carry occlusion or metal in B and A).
