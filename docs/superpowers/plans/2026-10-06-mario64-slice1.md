# Super Mario 64 tribute: slice 1 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playable Super Mario 64 tribute: Peach's castle (grounds and inside, five paintings, star doors) and Bob-omb Ridge with its three stars, in the Modern look, reached from the island's N64 and from `#/dot-matrix/64`.

**Architecture:** Pure, tested rules in `src/components/mario64/rules/` run at a fixed 30 Hz in SM64 units. Course files in `courses/` build both the collision triangles and the meshes through one kit. `scene.js` draws in metres (units × 0.01) on the runtime's renderer. `module.js` is the world module, and `Mario64.jsx` is the HUD over it.

**Tech stack:** React 19, three 0.186, vitest, the site's `src/runtime`, Poly Haven / ambientCG CC0 textures through `scripts/hq-assets.mjs`.

**Spec:** `docs/superpowers/specs/2026-10-06-mario64-design.md`

## Global constraints

- No Nintendo ROM, model, texture, music or sound. Everything is made in code or is CC0 / CC BY and credited.
- The rules never import three.js. They are SM64 units at 30 Hz: gravity 4/frame², terminal 75, run max 32, jump 42 + fwd/4, Mario 160 tall, radius 50.
- Yaw: 0 faces +Z; a heading's vector is `(sin yaw, cos yaw)`. Intended yaw = `camYaw + atan2(-stickX, stickY)`.
- Draw scale `S = 0.01` (units → metres).
- Save key `tp-m64`, version 1: `{ stars: { [courseId]: [bool, bool, bool] }, look: 'modern', sound: true }`.
- Star doors: Frosty Peak 1, Koopa Cove 3, Boo's Manor 5, Bowser 8. Slice 1 ships only Bob-omb Ridge's painting live; the other four paintings show "Coming soon" on their cards.
- A coin heals one wedge; every 50 coins in a visit give a life. Health is 0–8 wedges. Mario starts with 4 lives.
- File and copy style follows the repo: comments in plain sentences, no "we", the same kind of header comment as `dotmatrix/rules.js`.
- Lint (`npm run lint`), tests (`npm test`) and build (`npm run build`) pass before every push.

## Review focus

1. **A slow or hidden tab** (dt of seconds). The sim takes at most 4 fixed steps a frame and drops the rest, so nothing runs away. Test in Task 10.
2. **Seams between triangles** (Mario standing exactly on a shared edge or vertex). `findFloor` counts edges as inside, so he never falls through. Test in Task 1.
3. **Storage blocked** (private window). The game plays on with stars in memory. Test in Task 10.
4. **Closing the overlay mid-game** (Esc or the button while Mario is in the air). The world is disposed, the audio faded, the island draws again, and no keys stay held. Checked in Task 17's browser check.
5. **Touch stick and a button at once** (two fingers). Both register: the stick keeps its pointer id and the buttons take their own. Checked in Task 15's component logic and the browser check.

  - `wall pushes a point 30 from it out to radius 50, along its normal`.
  - `a point 60 behind a wall is not pushed`.
  - `a convex corner pushes out diagonally, not through`.
  - `ceiling found above, none below`.
  - `water level inside a box, -Infinity outside`.

- [ ] **Step 2:** Run `npx vitest run src/components/mario64/rules/collide.test.js`. Expected: FAIL (module missing).
- [ ] **Step 3: Implement.**
  - A surface is a floor when ny > 0.01, a ceiling when ny < −0.01, otherwise a wall.
  - The grid has 1024-unit cells. Each surface goes in every cell its xz bounds overlap, grown by 150.
  - Floor and ceiling heights come from the plane, `y = -(nx x + nz z + d) / ny`, with an inclusive barycentric test in xz (ε 1e-4).
  - Walls are one-sided, as in SM64. Skip a wall when the point is outside its y range or its plane offset is beyond ±radius. A projection inside the triangle pushes by `radius − offset` along the normal's xz. Otherwise, take the closest point on the edges: when its horizontal distance h is under the radius and the offset is above −1, push by `radius − h` away from it.
  - The raycast is Möller–Trumbore over the cells the segment's bounds cover, plus the dynamic colliders.
