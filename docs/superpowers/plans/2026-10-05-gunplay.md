# Gunplay and the crews on foot: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real guns held properly, aimed with the whole upper body, kicking when fired, with flashes and impacts, on every crew figure and trooper on foot; bodies that pace, leap, land, lean, flinch and fall.

**Architecture:** Pure IK math in `lib/three/ik.js` (tested in Node). One browser module, `universe/gunplay.js`, builds each gun and poses any figure on the shared Meshy skeleton (or the built figures' groups, given the same names) over its clips. `footScene.js` and the galaxy surface call it. The Federation's rules (`foot.js`) gain an `aim` number for the drawing to read.

**Tech Stack:** React 19, Vite 8, three.js r186, Vitest 5 (plain Node, no DOM), Playwright-core with the container's Chromium for screenshots.

**Spec:** `docs/superpowers/specs/2026-10-05-gunplay-design.md`

## Global Constraints

- No new models: this container can't reach Meshy or Sketchfab. Guns are built in code.
- The online wire format (`online/protocol.js`) doesn't change.
- Lint (`npx eslint .`), tests (`npx vitest run`) and the build (`npx vite build`) clean before each merge; one PR per part.
- Nothing in `shipModels.js, hulls.js, livery.js, modules.js, outfit.js, paint.js, Hangar.jsx` (another session's).
- Bone names (Meshy): Hips Spine02 Spine01 Spine neck Head head_end headfront LeftShoulder LeftArm LeftForeArm LeftHand RightShoulder RightArm RightForeArm RightHand LeftUpLeg LeftLeg LeftFoot LeftToeBase RightUpLeg RightLeg RightFoot RightToeBase. `Spine02` is lowest, `Spine` highest.
- Figures in `footScene.js` stand in map units (`METRE` = 0.027); guns are built in metres and scaled by `METRE` when attached there, by 1 on the galaxy's worlds.

## Review Focus

- A figure whose model never loads (the built Luke, or a guest's before its GLB lands) must still fire and aim without throwing: every bone lookup is optional.
- The hand's palm estimate can be wrong for a model: the override table in `gunplay.js` must be consulted first, and a wrong estimate must only turn the gun, never move the hand off the wrist.
- `aim` weights are eased, never snapped, so a lock appearing mid-walk doesn't jolt the arm.
- Recoil must settle within a second with no shot, and never grow without bound under held fire.
- Troops within arm's reach of a target (the gazorpian) never pull a gun they don't have.
