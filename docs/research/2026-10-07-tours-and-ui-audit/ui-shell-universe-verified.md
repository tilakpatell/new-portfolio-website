# UI audit, verified: the shell, the classic pages and the universe map (stream C)

This is the verification pass over `ui-shell-classic.md` (71 findings: S, T, L, R, H, D, M) and `ui-universe.md` (63 findings: F01–F63). Each finding was read through two lenses:

1. **Code.** The claim was checked at its `file:line` in the repo as it stood on 2026-10-07. Is it real? Is it already handled somewhere (a later rule, a coarse-pointer or theme override)? Does a comment at the site say it is deliberate? Which stream owns the files?
2. **Design.** The fix was judged against `design-taste-frontend` (sections 0–3 and 11) and the house-look spec (`docs/superpowers/specs/2026-10-07-audience-tours-and-ui-audit-design.md`, sections 5.1–5.4: the rules, the glossary, the kit). Would a strong designer make this change, or would it flatten the site’s character into a template? Many fixes were narrowed here, and the fix given below is the narrowed one, not the audit’s original.

**The rule:** a finding is kept only if it passes both. It has to be real, not already handled and not marked deliberate, and the design lens must not drop it.
